# Pharmentia R&D Club — Official Website 🧪✨

> **Where Ideas Become Innovation.**  
> The official student-driven Research & Development club of **AIKTC School of Pharmacy**, Anjuman-I-Islam's Kalsekar Technical Campus, New Panvel, Navi Mumbai.

---

## 📌 Overview

**Pharmentia R&D Club** is an academic and student-led platform designed to foster scientific curiosity, research methodology, novel formulation ideation, and scientific communication among pharmacy scholars. Through workshops, intercollegiate pitching competitions, journal reading circles, and faculty guidance, Pharmentia bridges the gap between traditional pharmacy curricula and modern pharmaceutical industry standards.

---

## ✨ Key Features & Highlights

- **Interactive 3D Flip Profiles:** Custom 3D flip card profiles featuring official headshots, designations, and bio descriptions for all committee members and faculty leadership.
- **Why It Began & Vision:** Interactive 3D retrospective card outlining the founding philosophy: *"From Curiosity → To Concept → To Innovation"*.
- **Legacy (2025–2026) Timeline:** Animated milestone timeline documenting key events:
  - `25/09/2025` — **Pharmabazz 1.0** Intercollegiate Pitching Competition
  - `06/11/2025` — **Ink Your Innovation Workshop** (Scientific Writing)
  - `06/12/2025` — **Cosmoprof India Delegation**
  - `28/03/2026` — **Graphical Abstract Workshop**
- **Research & Literature Hub:** Direct access links to global biomedical databases and open-access portals:
  - **PubMed / NCBI**
  - **ScienceDirect**
  - **Google Scholar**
  - **PubMed Central**
  - **DOAJ**
- **Hands-On Activities Gallery:** Real-world photo galleries showcasing computer lab workshops, stage assemblies, pitching competitions, and certificate distribution ceremonies.
- **Tribute to Leadership:** Dedicated recognition section honoring **Dean Dr. Shariq Syed** and **Club Mentor Prof. Abuzar Shaikh**.
- **Direct Gmail Web Composition:** Membership invitation form that opens pre-filled Gmail drafts directly in the browser (bypassing Microsoft Outlook).

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (Glassmorphism, CSS Grid/Flexbox, 3D Transforms), Vanilla JavaScript (ES6+).
- **Animations:** GSAP & ScrollTrigger.
- **Backend / Server:** Node.js, Express.js.
- **Database:** SQLite (`pharmentia.db`).

## 🚀 Quick Start & Local Setup

To run the Pharmentia website locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dakshal-max/pharmentia-web.git
   cd pharmentia-web
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local server:**
   ```bash
   node server.js
   ```

4. **Open in Browser:**
   Navigate to `http://localhost:5000` or open `index.html` directly in any modern browser.
